#+title: asahi-bluefin
#+subtitle: a personal, bluefin-inspired fedora asahi atomic image
#+options: toc:2

* purpose

this repository builds one arm64 bootable container image:

#+begin_example
ghcr.io/okwalerie/asahi-bluefin:latest
#+end_example

the image inherits fedora asahi remix silverblue and adds a deliberately
asahi-safe subset of the bluefin experience:

- homebrew, using bluebuild's brew module
- tailscale, using tailscale's official rpm repository
- automatic os, flatpak, and brew updates through =uupd=
- a deployment-aware =m1n1= refresh after a successful boot
- firefox from flathub for the complete media runtime, plus native chromium
- selected desktop applications, gnome extensions, and terminal conveniences
- the personal claude desktop, codex desktop, handy, ghostty, and emacs packages

the asahi kernel, mesa, firmware, audio configuration, desktop, and boot stack
come from the upstream image and are not replaced here.

* status

this is an unofficial personal image. neither fedora asahi remix, asahi linux,
universal blue, nor bluefin supports it.

the base image is itself experimental. automatic updates are staged but never
force a reboot. after the next deployment boots successfully, the image
refreshes =boot.bin= once for that deployment. a subsequent reboot is required
only to begin using the refreshed stage-2 boot payload.

the image carries a narrow compatibility patch for that command. rpm-ostree
canonicalizes files in =/usr= to an epoch-zero timestamp; unpatched
=update-m1n1= passes the timestamp to =gzip=, which exits with status 2 and
aborts the update. the image changes that invocation from =gzip -c= to
=gzip -nc= so no source filename or timestamp is embedded.

* rebase

wait for the github action to publish a successful image. then, from the
existing fedora asahi atomic silverblue installation, first install the image
without signature enforcement so its cosign policy is present locally:

#+begin_src sh
sudo rpm-ostree rebase ostree-unverified-registry:ghcr.io/okwalerie/asahi-bluefin:latest
sudo systemctl reboot
#+end_src

then select the signed image:

#+begin_src sh
sudo rpm-ostree rebase ostree-image-signed:docker://ghcr.io/okwalerie/asahi-bluefin:latest
sudo systemctl reboot
#+end_src

finally, authenticate tailscale:

#+begin_src sh
sudo tailscale up
#+end_src

homebrew is initialized on first boot. its executable is
=/home/linuxbrew/.linuxbrew/bin/brew= and is added to interactive shell paths.
the default flatpaks and flathub remote are installed system-wide for bazaar.

install the fast-moving user tools after homebrew is ready:

#+begin_src sh
blujust install-ai-cli
#+end_src

this installs or refreshes =hermes-agent=, =codex=, =claude-code=, and =uv=.
the daily =uupd= job subsequently owns their homebrew updates.

claude desktop bundles cowork, but its arm64 virtualization path needs access
to =/dev/kvm=. grant that once, then log out and back in:

#+begin_src sh
sudo usermod -aG kvm "$USER"
#+end_src

inspect automatic updates and the asahi boot refresh with:

#+begin_src sh
systemctl status uupd.timer asahi-bluefin-update-m1n1.service
journalctl -u uupd.service -u asahi-bluefin-update-m1n1.service
#+end_src

* rollback

the previous atomic deployment remains in the boot menu. it can also be
selected for the next boot with:

#+begin_src sh
sudo bootc rollback --apply
#+end_src
