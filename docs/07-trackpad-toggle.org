#+title: milestone 7: special-layer F3 trackpad toggle
#+date: 2026-07-29
#+options: toc:2

* objective

make the physical Apple F3 key on its default special-function layer toggle
only the internal trackpad, while preserving =Fn+F3= as normal =F3=.

* implementation

this is deliberately mutable per-user GNOME state, not an image default. the
live Fedora Asahi host uses the Apple SPI keyboard and =hid_apple= with
=fnmode=3=. in this mode the key without Fn uses the special-function path;
Fn selects the standard function key.

the kernel maps Apple special F3 to =KEY_SCALE= (evdev code 120). the standard
xkeyboard configuration maps that event to =XF86LaunchA=. GNOME's native media
key plugin exposes =touchpad-toggle=, so no keyboard interception daemon,
root-owned remap, custom script, or udev rule is required.

the applied setting is:

#+begin_src sh
gsettings set org.gnome.settings-daemon.plugins.media-keys \
  touchpad-toggle "['XF86LaunchA']"
#+end_src

this writes the current user's dconf database. it persists across logout,
reboot, and normal system-image rebases, but remains user-owned configuration:
an explicit user setting is intentionally not replaced by an image gschema
default.

* validation

on the target, the persisted binding read back as:

#+begin_example
touchpad-toggle binding=['XF86LaunchA']
touchpad send-events='enabled'
#+end_example

Physical validation confirmed the intended behavior:

- press F3 without Fn: toggle the internal trackpad;
- press F3 without Fn again: restore it;
- press Fn+F3: retain ordinary =F3= behavior.

Useful inspection commands:

#+begin_src sh
cat /sys/module/hid_apple/parameters/fnmode
gsettings get org.gnome.settings-daemon.plugins.media-keys touchpad-toggle
gsettings get org.gnome.desktop.peripherals.touchpad send-events
#+end_src

* rollback

Restore GNOME's inherited binding with:

#+begin_src sh
gsettings reset org.gnome.settings-daemon.plugins.media-keys touchpad-toggle
#+end_src

Or disable this assignment explicitly:

#+begin_src sh
gsettings set org.gnome.settings-daemon.plugins.media-keys touchpad-toggle "['']"
#+end_src
